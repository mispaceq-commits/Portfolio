# Михаил Голиков — Мини-брендбук (личный)

Личный мини-брендбук графического дизайнера **Михаила Голикова** (Golikov Mikhail).
Это одностраничное руководство по фирменному стилю на русском языке, собранное вокруг
авторского рукописного логотипа-подписи.

## Что внутри

- **Концепция «Кто я?»** — короткая позиционная формулировка и характер бренда.
- **Направление** — айдентика и брендинг, типографика, арт-дирекшн.
- **Логотип** — основной знак и варианты (Ink / White / Signal Red), монограмма «G»,
  охранное поле, минимальный размер, правила «можно / нельзя».
- **Цвет** — фирменная палитра с HEX / RGB / CMYK и рекомендуемым соотношением.
- **Типографика** — Unbounded (заголовки) + Inter (текст) и шрифтовая шкала.
- **Графические элементы** — знак «G», красный мазок, чернильный штрих.
- **Паттерны** — 4 бесшовных SVG-паттерна: «Подпись», «Мазки», «Капли», «Сетка +».
- **Применение** — визитка, аватар, постер.

## Палитра

| Цвет        | HEX       | RGB            |
|-------------|-----------|----------------|
| Ink         | `#0C0C0C` | 12 · 12 · 12   |
| Signal Red  | `#C60202` | 198 · 2 · 2    |
| Paper       | `#F2EEE6` | 242 · 238 · 230|
| White       | `#FFFFFF` | 255 · 255 · 255|

## Структура

```
index.html                     — страница брендбука
assets/
  css/brandbook.css            — стили
  logo/
    logo-black.svg             — основной логотип (Ink)
    logo-red.svg               — логотип (Signal Red)
    logo-white.svg             — логотип для тёмного фона (выворотка)
    monogram-black/red/white.svg — монограмма «G»
    brush-stroke.svg           — красный мазок
    ink-stroke.svg             — чернильный штрих
  patterns/
    pattern-monogram.svg       — «Подпись»
    pattern-strokes.svg        — «Мазки»
    pattern-dots.svg           — «Капли»
    pattern-cross.svg          — «Сетка +»
```

## Просмотр локально

```bash
python3 -m http.server 8123
# открыть http://localhost:8123/index.html
```

Шрифты Unbounded и Inter подключаются через Google Fonts (нужен интернет).
Все графические ассеты — векторные (SVG), масштабируются без потери качества.
